Pi-Desktop-Plus macOS first launch

Official GitHub Release builds are Developer ID-signed and notarized. After
moving Pi-Desktop-Plus.app to Applications, the app should open without extra steps.

If you are using a local or unsigned build and macOS says the app is damaged
or does not open, open Terminal and run:

xattr -r -d com.apple.quarantine /Applications/Pi-Desktop-Plus.app

Use this only for an app obtained from a trusted Pi-Desktop-Plus source. It removes
only Apple's quarantine attribute from Pi-Desktop-Plus.app. Signed and notarized
builds do not need it.

The macOS ZIP package also includes Pi-Desktop-Plus-macOS-open.command, which can
clear the same attribute and launch the app after installation.

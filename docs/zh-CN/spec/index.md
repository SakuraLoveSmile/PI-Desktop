# 规格地图

规格地图把整个英文技术库整理成八个主题域。中文页负责导览、摘要和阅读顺序；协议字段、代码术语和完整技术正文链接到同一份英文源事实。

## 八个主题域

| 主题 | 中文入口 | 你会在这里找到 |
|---|---|---|
| 产品 | [产品与范围](product/) | 定位、交付范围、操作模式和非目标 |
| 架构 | [架构与工程](architecture/) | 进程边界、技术栈、仓库结构和数据所有权 |
| 运行时 | [运行时核心](runtime/) | IPC、Agent、工具、Rust host、RPC 和模型 |
| 体验 | [用户体验](ux/) | 信息架构、国际化、设计系统和交互 |
| 安全 | [安全](security/) | 权限、路径、插件和进程隔离 |
| 交付 | [交付与验收](delivery/) | 里程碑、验收、E2E、变更和发布 |
| 插件 | [插件系统](plugins/) | 包格式、API、权限、生命周期和开发体验 |
| 决策 | [决策与元数据](meta/) | ADR、决策日志和开放问题 |

## 如何保持同步

中文主题页和英文目录使用相同的八个主题域、阅读顺序和关键入口。技术正文
发生变化时，更新英文规格、相关 ADR 和 E2E 测试计划；中文页面只维护可验证的
导航与摘要，避免生成另一套不可靠的协议副本。

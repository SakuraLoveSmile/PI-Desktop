# 上下文洞察

> **翻译说明：** 本页对应 [英文源规格](/spec/03-runtime/context-insights)。代码、协议字段和标识符保持原文；如有歧义，以英文版本为准。

## 用户入口

上下文洞察使用 PI-Desktop 的原生数据和界面，移植
[dsh-context](https://github.com/bowenliang123/dsh-context) 的上下文观察工作流。
优先评估插件方案的结论记录在 [ADR](../../../adr/context-insights-native-port.md)。

- 侧边栏入口显示跨会话用量、活动日历、组成和可搜索、可筛选的会话卡片。
- 会话工作面板在现有原生和插件工具旁提供 Context；输入框用量检查器指向同一看板。
- `/context` 在活动会话中打开对话框，在首页打开总览。查看或刷新不提交用户回合，也不调用模型。
- 视图默认值使用经过校验的设备本地偏好；视图切换独立于提供商配置和上下文管理设置。

## 数据契约与权威来源

`packages/shared/src/context-insights.ts` 拥有公开的 v1 契约。
`contextInsightsGet` 是经过发送者校验的只读 IPC，只面向 Desktop 会话。
`sessionId` 必填；`includeContent: false` 在总览读取中去掉大块内容；
`requestId` 将内容读取限定到选定请求。未知或已删除会话沿用既有错误契约。
原生 Pi 与远程会话不能被呈现成已采集的本地 Desktop 会话。

运行时在每次提供商请求中采集逻辑 Pi 系统提示、模型可见工具 schema 和消息项。
适配器提供 `onPayload` 回调时，还会在现有扩展转换之后采集单独标注的提供商载荷。
`captureSource` 和 `contentRevision` 区分这两者；分类估算不得冒充传输字节的精确组成。
不提供该回调的插件适配器明确标为仅有 Pi 上下文。采集记录请求身份、回合/步骤、
模型/提供商、模式、模型窗口、开始/结束时间、状态和可用的实际用量。
采集不会修改上下文、模型选项、提供商 headers、取消信号或工具执行。

内容分为七类：system、tools、user、injected、skill、assistant 和 tool result。
文本/JSON 安全渲染；图片仅保留元数据，不保留二进制载荷。不会采集 header 凭据。
提供商载荷中的认证字段和 Gemini/Anthropic/OpenAI/Bedrock 图片二进制表示替换为
脱敏标记或元数据；载荷与请求内容共用预算。用量校准后的提示估算和未校准的内容
估算是不同量，分类合计不得宣称等于实际提供商用量或校准后的占用。

Host 在现有持久化边界内拥有诊断记录。最多保留 40 个请求、160 个事件、每请求
120,000 字符、每会话 1,200,000 字符。超出总预算时按完整请求退役。
丢弃请求/事件的数量和条目/内容截断标记可见；元数据缺失与采集截断分开表示。
删除会话同时退役诊断数据；读取和迟到写入不能重建已删除会话。
重启保留尚在预算内的采集记录，不变更 schema，也不重放中断的提供商请求。

既有 Host 用量历史独立于诊断保留策略，继续作为计费权威。
总览令牌/活动数据使用该历史；保留请求的费用和会话卡片标明有限覆盖范围。
缺失用量、费用、时间或窗口元数据表示未知，不制造零值报告。

## 检查行为

看板标识最新**已发出**请求，不声称在运行时空闲时显示精确的下一次请求。
步骤/回合选择、总量和带符号变化趋势使用已采集请求。固定选中项绑定持久请求身份；
悬停预览不会丢弃该选择。内容按需加载；内容 revision 使旧 hydration 失效。
持久化确认之后触发可见读取，避免先到的运行时事件让结束状态漏读。
旧会话或旧选择的迟到响应不能替换当前视图；缺失或已退役采集有明确状态。

上下文浏览器按类别折叠内容，支持搜索、工具排序、助手类型筛选和安全的原始/Markdown 阅读。
组成图同时展示内容估算、运行时占用以及提供商报告的 prompt/output/cache 数值。
变化项区分真实的压缩、修剪、模型、模式和注入事实，不为填满图表编造事件。
原有上下文管理行为保持不变。

文件活动和智能体关系使用已记录的 PI 工具/委派及现有会话/Team 所有权。
路径通过已有工作面板文件边界打开；请求元数据不能授权读取任意文件系统内容。
操作/时间统计标明保留请求或转录的覆盖范围。

总览提供 7 天/30 天/全部、特定日期筛选、项目/搜索/排序、有界元数据读取和分页。
本地日历分桶沿用既有 Host 用量历史的时间约定，以本地午夜而非 UTC 日期截断。
打开会话先走普通会话选择流程，再打开归属于该会话的看板。

## 兼容与验证

过去的请求未保留组装后的上下文，不能精确回填。没有历史采集的会话仍可读取，
并明确标注未采集。本次移植不删除转录、不改变模型/提供商默认值、不扩张插件权限，
也不新增自动压缩/修剪。DSH 特有 PTC 预设、余额凭据和图片令牌公式不是 PI 执行契约；
仅展示现有 PI 事实，未知值明确标记。

使用隔离提供商夹具、Host 持久化/重启/删除测试、组件交互测试和定向原生/浏览器用户路径验证。
静态检查和夹具测试不构成真实提供商计费、物理设备或已发布版本证据。

## BUG fix: top bar controls not clickable (Electron drag region)
- User reported the drag area covered the bar so buttons couldn't be clicked.
- Root cause: `.conversation-topbar` had `-webkit-app-region: drag` AND
  `pointer-events: none`. In Electron the drag region INHERITS to all children
  regardless of `pointer-events`, so every button was a drag target. `pointer-events`
  does NOT solve this.
- Fix: removed `pointer-events: none` from the bar; set `.ct-left`/`.ct-right`
  (the interactive clusters) to `-webkit-app-region: no-drag`; re-set
  `.ct-title-wrap` to `drag` so the title stays draggable. Dropdown menu lives
  inside `.ct-right` (no-drag) so it's clickable too.
- Lesson (reusable): in frameless Electron, parent drag + child no-drag is the
  only way to keep buttons clickable; never rely on pointer-events for this.
- Committed + pushed as second commit on feat/conversation-topbar (PR #112 updated).
